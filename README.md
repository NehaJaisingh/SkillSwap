#  SkillSwap

# Exchange Skills. Learn Together.

SkillSwap is a peer-to-peer skill exchange platform where users can **teach skills they know and discover skills they want to learn**.

# Features

- 👤 User profiles
- 🧠 Teach / Learn skill management
- 🤝 Skill matching
- 📩 Skill-swap requests
- 📊 Activity dashboard
- ⭐ Reviews and sessions

# Tech Stack

- Python
- Streamlit
- MySQL
- MySQL Connector
- Git & GitHub

# Database

MySQL relational database containing:

`users` · `skills` · `user_skills` · `swap_requests` · `swap_sessions` · `reviews`

The project demonstrates **CRUD operations, primary and foreign keys, JOINs, filtering, aggregation, and Python–MySQL connectivity**.
